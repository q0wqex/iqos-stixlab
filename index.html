Хостинг на GitHub Pages

Это приложение полностью статично и готово для бесплатного размещения на GitHub Pages:

  1. Создайте репозиторий на GitHub (например, iqos-sticks).
  2. Загрузите файлы index.html, style.css, data.js, app.js.
  3. В репозитории перейдите в Settings > Pages и выберите Branch: main.
  4. Откройте полученную ссылку на своих телефонах и сохраните как веб-приложение!
