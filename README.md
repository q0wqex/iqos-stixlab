# 💨 STIX LAB — Приложение для совместной оценки стиков IQOS

Современное веб-приложение, созданное специально для пар, чтобы вместе дегустировать, оценивать и находить идеальные стики для IQOS (TEREA, HEETS, FIIT).

---

## ✨ Возможности

- **Парная оценка (Он + Она):**
  - Раздельные оценки от 0 до 10 с шагом 0.5 для каждого партнера.
  - Персональные вердикты: «❤️ Купим снова», «🤔 Так себе», «❌ Ни за что».
  - Личные комментарии и вкусовые заметки к каждому стику.
  - Настройка имен и аватарок в профиле.

- **Большой предустановленный каталог:**
  - **TEREA (IQOS ILUMA):** Amber, Bronze, Silver, Yellow, Turquoise, Purple Wave, Mauve Wave, Green Zing, Oasis Pearl, Sun Pearl, Sienna, Ruby Fuse и др.
  - **HEETS (IQOS Originals / Duo):** Amber, Yellow, Bronze, Purple Wave, Turquoise, Green Zing, Tropical Swift, Silver и др.
  - **FIIT (lil Solid):** Viola, Crisp, Regular, Marine, Spring.
  - Фильтры по брендам, категориям (Табак, Ягоды, Ментол, Цитрус, Капсула) и статусу («Оценены обоими», «Непробованные», «В избранном»).
  - Добавление собственных вкусов с выбором цвета пачки и параметров крепости / ментола.

- **Наш Топ и Рейтинги:**
  - 👑 **Абсолютный чемпион пары** — стик с максимальным суммарным баллом.
  - ⚡ **Яблоко раздора** — стик с самым большим расхождением во вкусах (повод поспорить или передегустировать!).
  - Персональный Топ-5 Парня и Девушки.
  - Общая таблица лидеров с возможностью скопировать рейтинг в Telegram.

- **Индекс гармонии и совместимости:**
  - Расчет % совпадения вкусовых предпочтений.
  - Сравнение любви к категориям (Табак vs Ягоды vs Ментол).
  - Персональная рекомендация для покупки в табачном магазине.

- **Слепая дегустация (Blind Tasting Mode):**
  - Интерактивная мини-игра: один партнер вставляет стик в IQOS не показывая пачку, второй пробует вслепую и оценивает, после чего тайна раскрывается!

- **Рулетка вкусов («Что покурить сегодня?»):**
  - Поможет быстро выбрать пачку на вечер случайным образом.

- **Список совместных покупок («Купить снова»):**
  - Автоматически собирает стики, получившие вердикт ❤️ от обоих или хотя бы одного.
  - Кнопка для быстрой отправки списка покупок в мессенджер.

- **Синхронизация и сохранность данных:**
  - Автоматическое сохранение в `localStorage` браузера.
  - Экспорт и импорт в JSON (легко перенести оценки с телефона на телефон).

## 🚀 Как запустить на GitHub Pages (за 1 минуту)

Приложение полностью статическое (чистый HTML5, CSS3, JavaScript) и не требует серверов или баз данных.

1. **Создайте репозиторий на GitHub:**
   - Перейдите на [github.com/new](https://github.com/new).
   - Назовите репозиторий, например: `iqos-stixlab`.
   - Сделайте его **Public**.

2. **Загрузите файлы:**
   - Загрузите в репозиторий файлы из этой папки:
     - `index.html`
     - `style.css`
     - `data.js`
     - `app.js`
     - `README.md`

3. **Включите GitHub Pages:**
   - В вашем репозитории перейдите во вкладку **Settings** (Настройки).
   - В левом меню нажмите **Pages**.
   - В блоке **Build and deployment** выберите Source: **Deploy from a branch**.
   - Выберите ветку **main** (или `master`) и папку `/ (root)`, затем нажмите **Save**.

4. **Готово!**
   - Через 30–60 секунд GitHub выдаст ссылку вида:  
     `https://ВАШ_НИК.github.io/iqos-stixlab/`
   - Откройте эту ссылку на телефоне, нажмите **«Поделиться» -> «На экран "Домой"»** (iOS) или **«Установить приложение»** (Android), чтобы пользоваться как нативным приложением!
